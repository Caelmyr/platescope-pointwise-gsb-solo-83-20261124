# PlateScope 薄层色谱读板

PlateScope 用已拍摄的薄层色谱板照片复核染料、墨水等显色带。照片库保存板照与标定，读板记录保存一次分析的设定、读数和原片位置。

运行 `./start.sh`，打开 [本地读板台](http://127.0.0.1:19886/)。默认使用独立 Compose 项目与命名数据卷。用 `PLATESCOPE_PORT` 可更改本地端口。运行 `./start.sh stop` 停止服务，照片和读板仍保存在卷中。

1. 选择「载入练习板」，或导入展开方向向上的 PNG、TIFF、JPEG 原片。练习板是合成墨水板，第一道作为参照，第二道为样品。
2. 用「框选板区」点两个角，设置泳道数，再标出「溶剂前沿」和「起跑线」。框内等分泳道。用「保留标定」为本板持续使用这些设置。溶剂前沿不水平时，在「设溶剂前沿」里依次点左、右两个端点，起跑线仍点一条横线；两端点在同一高度时自动按水平前沿处理。
3. 「显色带」给出当前道每条带的 Rf、像素支持区和显色积分。「泳道质检」查看整板条数与位置。「显色曲线」沿泳道给出显色变化，点击曲线能回到对该读数有贡献的原片像素（含支持区矩形与像素数）。
4. 「参照查找」给出当前道各带的最近参照。「相对显色量」根据指定的样品和参照带序号给出显色积分比值。
5. 「底色巡检」分段查看亮底极差与明暗裁切。「拖尾读数」给出可量色带的半高宽比。「色彩分量」显示每条带的红、绿、蓝显色积分相对占比。点各结果行可回原图。
6. 「保存读板」可从照片的读板记录重开，下载 CSV 或带标记的同尺寸 PNG。也可在「照片准备」调整曝光、色彩、配准或组合照片，把生成的一张结果送到读板台。

单张照片不超过 22 MB，每边至少 32 像素，总像素不超过 1400 万。16 位灰度照片保留量程用于分析，浏览器预览与标记图可降至 8 位。带序号沿起跑线向前沿递增。水平前沿的 Rf 为显色带加权中心相对两条水平标定线的归一化距离；标出倾斜前沿两端后，每列像素按该列自己的起跑线—前沿跑程折算 Rf，整条泳道汇入同一个 Rf 网格，斜着显出来的带不再被整行平均摊宽。Rf 分箱宽度由道内最短跑程决定，保证最短的一列在每个箱内至少有两个真实像素行，短跑程一侧不会出现没有像素支持的虚假尖峰；平滑量按一个分箱宽度计，两条相距很近的细带只要超过约两个分箱即可分开。显色读数基于压缩或未校色的数字像素和均匀底色近似，只适用于同板、同通道的相对复核。半高宽超出带界时留空。水平前沿仍按道内平均显色的连续行定位，倾斜前沿按 Rf 分箱定位，原有近邻查找不保证一对一。该工具不推断化学物质，也不输出绝对浓度。

正常容器使用锁定的 Python 3.12 依赖，项目同时支持已锁定的 Python 3.11 环境。可以用 `python3 scripts/count_backend.py --project-root . --source-root platescope --source-root image_lab --output backend-count.json` 复算后端有效行。
